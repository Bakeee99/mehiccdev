  mehiccdev — TIM v2: premium redizajn + kvadratne slike (LinkedIn)
════════════════════════════════════════════════════════════════════

Traži lib/useReveal.ts iz velikog paketa popravki (mora biti unutra
prije ovoga).

ŠTA JE U ZIP-u (1 fajl):
  components/sections/About.tsx

────────────────────────────────────────────────────────────────────
GLAVNA STVAR: SLIKE VIŠE NEĆE BITI IZREZANE
────────────────────────────────────────────────────────────────────
Stari dizajn je imao ŠIROKI foto baner preko cijele kartice, pa bi
kvadratna LinkedIn slika (400×400) bila odsječena po pola glave.
Novi dizajn ima KVADRATNI foto okvir (176×176 na desktopu) s
gradijentnim rubom, u koji LinkedIn slika sjeda 1:1, bez rezanja.

KAKO UBACITI SLIKE (3 koraka):
  1. Skini profilnu sliku s LinkedIn-a: otvori svoj profil → klikni
     na sliku → desni klik → "Sačuvaj sliku kao" → bakir.jpg
     (isto Nedim → nedim.jpg)
  2. Spremi obje u  public/team/  (taj folder VEĆ POSTOJI u projektu)
  3. U About.tsx, pri vrhu u PHOTOS, upiši:
       src: "/team/bakir.jpg"   (prvi red, BM)
       src: "/team/nedim.jpg"   (drugi red, NK)
     Placeholder s inicijalima se sam sakrije.

Savjet: ako LinkedIn ponudi malu sliku, otvori profil u browseru,
zumiraj sliku (klik na nju) pa tek onda sačuvaj, dobiješ veću
rezoluciju. Sve preko 400×400 piksela je sasvim dovoljno.

────────────────────────────────────────────────────────────────────
ŠTA JE JOŠ NOVO U DIZAJNU
────────────────────────────────────────────────────────────────────
  • Naslov: "Ljudi iza mehiccdev-a" (serif gradient akcenat, kao
    ostale sekcije). Ličnije od "Ko smo mi".
  • Kartice: slika lijevo (s gradijentnim rubom i blagim zumom na
    hover), sadržaj desno; na telefonu slika centrirana iznad.
  • Uloga sada ima svoju ikonicu (kod za tebe, megafon za Nedima).
  • Dodano LinkedIn dugme na svakoj kartici ("LinkedIn profil") koje
    otvara profil u novom tabu. Prije je cijela kartica bila link,
    što niko ne skonta; jasno dugme je bolje.
  • Dekor: grid šara + sjaj koji se pojača na hover, kartica se
    podigne.
  • Prebačeno na useReveal pattern, tekstovi self-contained (BS/EN),
    id sekcije ostaje "o-nama" pa navigacija radi kao prije.

────────────────────────────────────────────────────────────────────
KORACI:
────────────────────────────────────────────────────────────────────
  1. Raspakuj u KORIJEN projekta → "Zamijeni" DA
  2. Ubaci slike po uputi gore (možeš i poslije, placeholder je uredan)
  3. npm run dev → provjeri: slike (bez rezanja!), LinkedIn dugmad,
     oba jezika, obje teme, telefon
  4. git add . && git commit -m "feat: tim v2, kvadratne slike + redizajn" && git push
