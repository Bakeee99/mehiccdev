  mehiccdev — NOVI Hero (split layout + 3D sfera tačkica)
═══════════════════════════════════════════════════════════

ŠTA JE NOVO:
  • Split layout: tekst lijevo (badge, naslov, opis, CTA, statistike),
    3D sfera tačkica desno U POZADINI.
  • Naslov ima elegantan italic serif akcenat na "transformiran kodom"
    (kao na referentnom dizajnu).
  • Sfera = mreža svjetlećih tačkica s tankim linijama (tvoj "network
    s klijentima"), rotira se lagano.
  • Statistike su sad tanki red brojeva (ne velike kartice).
  • Tech pills (Next.js, React...) su izbačeni iz hera — čišći prvi dojam.

TEHNIČKI DETALJI (bitno):
  • Sfera je čisti canvas + JavaScript — NEMA novih biblioteka,
    ništa se ne instalira, sajt ostaje brz.
  • NE ODSIJECA SE: veličina je matematički izračunata tako da sfera
    kroz CIJELU rotaciju ostaje unutar okvira (testirano na više
    veličina ekrana — 0px prekoračenja).
  • U pozadini je (pointer-events: none) — ne smeta klikovima ni čitanju.
  • Na mobitelu je iza sadržaja na 28% vidljivosti — suptilno, ne smeta.
  • Poštuje "reduced motion" postavku (statična za osjetljive korisnike).
  • Koristi postojeće i18n tekstove — NIŠTA drugo ne treba mijenjati.

ŠTA JE U ZIP-U:
  components/sections/Hero.tsx   (jedan fajl — kompletan novi hero)

KAKO UBACITI:
  1. Raspakuj U KORIJEN projekta (gdje su folderi components, lib, app).
  2. "Replace / Zamijeni?" → DA.
  3. npm run dev  → provjeri hero (BS/EN, dark/light, mobitel).
  4. git add . && git commit -m "Novi hero: split layout + 3D network sfera" && git push

NAPOMENA:
  • Provjereno: cijeli projekat se uspješno builda (npm run build).
