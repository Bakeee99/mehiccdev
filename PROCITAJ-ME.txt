  mehiccdev — SAMO TAMNA TEMA + JEZIČKI SLIDER SA ZASTAVICAMA

ŠTA JE U ZIP-u (2 fajla):
  app/layout.tsx
  components/sections/Navbar.tsx

ŠTA JE PROMIJENJENO:
1. SVIJETLA TEMA JE UGAŠENA: sajt je trajno u tamnoj temi
   (forcedTheme="dark"). Ovo važi i za posjetioce kojima je ranije
   ostala zapamćena svijetla tema u browseru: prisilno se pregazi.
   Sunce/mjesec dugme je uklonjeno iz navbara.

2. JEZIK KAO SLIDER SA ZASTAVICAMA: umjesto "🌐 BS" teksta, sada je
   pilula s dvije zastavice (BiH i UK) i klizačem koji označava
   aktivni jezik. Klik na zastavicu bira taj jezik (nema slijepog
   prebacivanja), neaktivna zastavica je prigušena. Na prvi pogled
   je jasno čemu služi.

   Tehnički detalj: zastavice su mini SVG crteži, NE emoji, jer se
   emoji zastave na Windowsu prikažu kao slova ("BA", "GB").

KORACI:
  1. Raspakuj u KORIJEN → "Zamijeni" DA
  2. npm run dev → klikni obje zastavice (klizač prelazi, jezik se
     mijenja), provjeri da teme dugmeta više nema i da je sajt taman
     čak i ako ti je ranije bila upaljena svijetla tema
  3. git add . && git commit -m "feat: samo tamna tema + jezicki slider" && git push

Build verifikovan prije slanja: npm run build ✓
