ŠTA JE NOVO: dva PONAŠANJA (ne nove teksture)
────────────────────────────────────────────────────────────────────
1. REFLEKTOR KOJI PRATI MIŠ (desktop): mekan plavi sjaj od ~900px
   klizi po stranici za kursorom, s oprugom (glatko, bez trzaja).
   Gdje god posjetilac krene, sajt "svijetli" s njim. Ovo se
   primijeti u prvoj sekundi i niko ga nema.

2. AMBIJENT KOJI PUTUJE SA SKROLOM: na vrhu sajta svjetlo dolazi
   odozgo (plavo); kako skrolaš prema dnu, ono blijedi a iz dna
   izvire novo, indigo/cijan svjetlo (dva izvora, lijevo i desno).
   Stranica postaje putovanje kroz svjetlo: nijedan ekran nema istu
   pozadinu. Tehnički se mijenja SAMO prozirnost dva sloja (GPU,
   jeftino), nikad sami gradijenti.

Šine s pulsom, blueprint skice i zrno ostaju ispod svega (v2).

TELEFON / REDUCED MOTION: reflektor i putovanje ambijenta su
isključeni (statično gornje svjetlo + zrno). Mobilna dijeta
netaknuta: skrol handler je pasivan i rAF-ograničen, radi samo
na desktopu.

KORACI:
  1. Raspakuj u KORIJEN → "Zamijeni" DA
  2. npm run dev → desktop: mrdaj mišem (reflektor), pa POLAKO

     obje teme; pa telefon (statično, glatko)
  3. git add . && git commit -m "feat: pozadina v3, ambijent + reflektor" && git push
