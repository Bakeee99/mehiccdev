  mehiccdev — POZADINA v2: "ŽIVI SISTEM"
════════════════════════════════════════════════════════════════════

Zamjenjuje prethodni "potpisni sloj" ZIP (sve iz njega je unutra i
nadograđeno). Hero.tsx iz prethodnog ZIP-a i dalje vrijedi ako si ga
već ubacio; ako nisi, ubaci i njega (konsolidovana aurora).

ŠTA JE U ZIP-u (3 fajla):
  components/ui/BackgroundFX.tsx  → NOVA komponenta, sva pozadina
  app/layout.tsx                  → koristi novu komponentu
  app/globals.css                 → keyframes za puls + zrno

────────────────────────────────────────────────────────────────────
ŠTA JE NOVO (liječi "monotono i repetitivno")
────────────────────────────────────────────────────────────────────
1. PULS KROZ ŠINE: kratki svijetli signal putuje niz lijevu šinu
   (plavi, 9s ciklus) i desnu (svjetliji, 14s, pomaknut start), kao
   podatak koji teče kroz sistem. Nikad nisu sinhronizovani pa
   pozadina stalno "radi". Čist CSS transform, nula troška.

2. BLUEPRINT SKICE PO DUBINI STRANICE: pet blijedih wireframe
   crteža (browser s kotom "320px", telefon s REZERVIŠI dugmetom,
   dijagram toka UPIT → SISTEM → ✓ 2s) na različitim visinama
   (115vh, 240vh, 390vh, 540vh, 680vh), naizmjenično lijevo/desno,
   svaka blago zarotirana. Skroluju SA sadržajem, pa svaki dio
   stranice ima drugačiju pozadinu. Ovo je "IT fazon" bez klišeja:
   ne sija, ne treperi, nego izgleda kao stol arhitekte softvera.

3. Svjetlo s vrha, šine i zrno ostaju kao podloga.

Performanse: nula JavaScripta, nula blur filtera, animacija je samo
transform. Na telefonu: samo svjetlo + zrno (šine, puls i skice su
desktop detalj, mobilna dijeta netaknuta). motion-reduce gasi puls.

NAPOMENA: pozicije skica su u vh jedinicama (dubina stranice). Ako
ti neka sjedne ružno preko sekcije, pomjeranje je trivijalno: u
BackgroundFX.tsx u BlueprintLayer promijeni top-[XXXvh] vrijednosti.

KORACI:
  1. Raspakuj u KORIJEN → "Zamijeni" DA (BackgroundFX.tsx je nov)
  2. npm run dev → skrolaj CIJELI sajt na desktopu: puls kroz šine,
     skice na različitim dubinama; provjeri obje teme pa telefon
  3. git add . && git commit -m "feat: pozadina v2, zivi sistem" && git push

Build verifikovan prije slanja: npm run build ✓
