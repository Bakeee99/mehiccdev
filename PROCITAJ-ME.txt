Zamjenjuje prethodni Portfolio (mehiccdev-novi-portfolio.zip).
I dalje traži lib/useReveal.ts iz velikog paketa popravki, pa taj
paket mora biti ubačen prije ovoga.

ŠTA JE U ZIP-u (1 fajl):
  components/sections/Portfolio.tsx

────────────────────────────────────────────────────────────────────
ŠTA JE PROMIJENJENO U ODNOSU NA v1
────────────────────────────────────────────────────────────────────
1) LAPTOP + TELEFON MOCKUP (umjesto onog grubog kalendara)
   • Laptop okvir s ekranom u 16:10 formatu: tu ide screenshot
     NASLOVNE stranice aplikacije.
   • Preko laptopa, zdesna, nagnut telefon okvir (s notchom):
     tu ide screenshot ADMIN PANELA u uspravnom formatu.
   • Dok screenshotovi ne stignu, u okvirima su uredni placeholderi
     koji glume aplikaciju (nav, naslov, kartice vozila; na telefonu
     lista rezervacija sa statusima).
   • Cijela kompozicija ima blagi 3D nagib koji se ispravi na hover.

2) BOČNE KARTICE BEZ PRAZNOG PROSTORA
   • Kartice su sada vertikalne: gornji dio je vizual (gradijent s
     grid šarom) koji se RASTEŽE i popunjava svu visinu, dolje su
     naslov, opis i strelica.
   • Na vizualu stoji kategorija projekta (pilula), a OxyBaric ima
     i zelenu "Uživo" oznaku.
   • Na hover: kartica se podigne, šara na vizualu se blago zumira.

────────────────────────────────────────────────────────────────────
UBACIVANJE PRAVIH SCREENSHOTOVA (2 minute posla)
────────────────────────────────────────────────────────────────────
  1. Slike spremi u  public/portfolio/  npr.:
       maximum-naslovna.png        (naslovna, širi format, 1600×1000)
       maximum-admin-mobitel.png   (admin panel, USPRAVNI/telefon format)
  2. U Portfolio.tsx pri vrhu upiši putanje:
       const SCREEN_DESKTOP = "/portfolio/maximum-naslovna.png";
       const SCREEN_MOBILE  = "/portfolio/maximum-admin-mobitel.png";
  3. Placeholderi se sami sakriju.

  VAŽNO za admin screenshot: zamagli imena, telefone i emailove
  gostiju prije nego što slika ode na javni sajt!

────────────────────────────────────────────────────────────────────
KORACI:
────────────────────────────────────────────────────────────────────
  1. Raspakuj u KORIJEN projekta → "Zamijeni" DA
  2. npm run dev
  3. Provjeri oba jezika, obje teme, mobilni raspored (bočne kartice
     idu ispod glavnog bloka), hover na mockup i kartice
  4. git add . && git commit -m "feat: portfolio v2, device mockup + pune kartice" && git push
