────────────────────────────────────────────────────────────────
IZMJENA 1: labela, u objektu LABELS (dva reda, bs i en)

  bs: { ..., solutions: "Rješenja", maximum: "Maximum" },
  en: { ..., solutions: "Solutions", maximum: "Maximum" },

Dakle samo dopiši `maximum: "Maximum",` na kraj oba reda.

────────────────────────────────────────────────────────────────
IZMJENA 2: stavka u meniju, u nizu NAV_LINKS

Dopiši ovaj red odmah IZA stavke za portfolio:

    { label: L.maximum,   href: "/maximum", badge: "case" },

Ako NAV_LINKS nema polje `badge`, onda samo:

    { label: L.maximum,   href: "/maximum" },

ALTERNATIVA KOJU PREPORUČUJEM

Navbar već ima šest stavki, dropdown "Rješenja", prekidač jezika i
dugme Kontakt. Zbog toga smo desktop meni već pomjerili da se
prikazuje tek od 1024 px. Sedma stavka gura ga nazad u gužvu.

Čistije: ubaci Maximum u postojeći dropdown "Rješenja", jer je taj
niz i napravljen da primi još stavki. U nizu SOLUTIONS dopiši:

  {
    href: "/maximum",
    label: { bs: "Maximum, case study", en: "Maximum, case study" },
    desc:  { bs: "Kako je sistem nastao", en: "How the system was built" },
  },

Time meni ostaje iste širine, a stavka je tačno tamo gdje je
posjetilac traži.
